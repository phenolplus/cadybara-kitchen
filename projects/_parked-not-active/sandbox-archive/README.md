# Sandbox Archive

This project is cold storage for things that are not part of the current clean
workflow.

It owns:

- `legacy-docs/` - old React/FastAPI/SQLite design direction.
- `workspace/archive/` and `workspace/archives/` - old preserved run snapshots.
- `workspace/external/` - copied external scratch repos.
- `workspace/gauntlets/` - one-off SDF/CadQuery visual experiment.
- `workspace/loose-files/` and `workspace/tmp/` - miscellaneous historical
  files, demos, and temporary outputs.

Use this folder when you want to preserve context without letting it steer the
active project structure.
